# 文件日志模式（`l`）

## 需求

在 `变化(C)` 列表中对当前文件按 `l`，进入“文件日志模式”，交互与 `SVN 日志(L)` 一致，但日志只包含当前文件：

- 左侧显示该文件的日志列表；
- 右侧显示选中日志版本中该文件的差异；
- `→` 把焦点切到右侧窗口；
- `↑`/`↓` 切换日志版本，右侧差异随之更新；
- `Esc` / `←` 返回或退出。

## 布局

```
┌ 文件日志 (2) [焦点]  → 右键切换到右侧 ┐┌ 差异: r3 README.md   + 切换差异方式  Esc 返回日志列表 ┐
│ > r3 ... alice  补充使用文档...        ││        旧                 |        新                 │
│   r1 ... alice  初始化项目骨架...      ││ ...                                               │
└────────────────────────────────────────┘└───────────────────────────────────────────────────┘
```

- 左侧：`文件日志 (n)`，条目格式与日志 tab 的 Log 列表一致（版本、日期、作者、消息首行）。
- 右侧：`差异: rN <path>`，默认左右对比，`+` 切换统一格式。
- 焦点边框：左侧/右侧分别高亮；`→` 进入右侧后，`↑`/`↓` 仍切换左侧选中的日志版本。

## 按键

| 按键 | 左侧焦点 | 右侧焦点 |
| --- | --- | --- |
| `↑` / `k` | 上一条日志（顶部再按进入 tab 栏） | 上一条日志 |
| `↓` / `j` | 下一条日志 | 下一条日志 |
| `g` / `G` | 第一条 / 最后一条 | 同左 |
| `→` | 焦点切到右侧差异窗口 | — |
| `←` | — | 焦点回左侧日志列表 |
| `Enter` | 焦点切到右侧并加载差异 | 重新加载差异 |
| `+` | 切换左右/统一差异 | 同左 |
| `Esc` | 退出文件日志模式，回到 Changes | 回到左侧日志列表 |
| `L` / `Tab` / `C` | 切换 tab（离开文件日志模式） | 同左 |

## 与 `SVN 日志(L)` 的差异

| 项 | `SVN 日志(L)` | 文件日志（`l`） |
| --- | --- | --- |
| 日志范围 | 整个仓库 | 仅当前文件 |
| 中间层 | 左 Log + 右 Files（该版本的变更文件） | 无 Files 层，直接左 Log + 右 Diff |
| 右侧内容 | Files 列表 / Diff | 始终为当前文件在该版本的 Diff |

## 实现

- `model` 增加 `fileLog bool`、`fileLogPath string`，复用 `modeLog` 的日志状态。
- `l` 键：保存当前预览快照 → `openFileLog(path)` → 执行
  `svn log --xml -l 20 <path>`（`fetchFileLogCmd`）。
- `logListMsg` 增加 `fileLog` / `path` 字段；文件模式加载完成后选中第一条并触发
  `fileLogDiffCmd(rev, path)`（`svn diff -c rev <path>`）。
- 渲染分支：
  - `renderLeftPane`：`modeLog && fileLog` → 日志列表（`renderLogPane`，标题 `文件日志 (n)`）；
  - `renderRightPane`：`modeLog && fileLog` → `renderLogDiffPane`（带焦点参数）。
- `handleLogKey`：`fileLog` 时走 `handleFileLogKey`（上下切换日志、左右切换焦点、Esc 两级退出）。
- 退出文件模式时清空日志缓存，避免 `openLogTab(false)` 误用单文件日志。

## 验证

1. `变化` 中选中 `README.md` 按 `l`：左侧 `文件日志 (n)`，右侧 `差异: rN README.md`。
2. `↓`/`↑`：左侧光标移动，右侧标题与内容随版本变化。
3. `→`：右侧边框高亮；此时 `↓`/`↑` 仍切换日志并刷新差异。
4. `←`：回到左侧；`Esc`：退出，左侧恢复 `变化` 列表，右侧恢复进入前的预览。
5. `+`：左右对比 / 统一格式切换。
6. `L`：进入完整 `SVN 日志` tab（不混入单文件日志）。
7. 使用独立 checkout 副本验证，不修改 `tmp/wc`。
